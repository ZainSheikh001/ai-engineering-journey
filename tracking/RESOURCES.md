# Free resources

## LLM access (free)
- Google AI Studio — Gemini API free tier: https://aistudio.google.com
- Groq — free tier for open models: https://console.groq.com
- Ollama — run models locally: https://ollama.com
- Google Colab (free GPU): https://colab.research.google.com
- Kaggle Notebooks: https://www.kaggle.com/code
